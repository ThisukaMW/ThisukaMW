## 🚀 Featured Projects

### 🏆 [ResolveX](https://github.com/ThisukaMW/ResolveX) — Real-Time Delivery Fault Detection & Resolution
**Champions — CodeArena'26** (KDU × Dialog Axiata PLC) · [Live Demo](https://resolvex-app.vercel.app/)

`FastAPI` `React` `Supabase` `scikit-learn` `XGBoost` `Gemini Vision`
- Four ML models (Random Forest, Isolation Forest, calibrated XGBoost) for fault attribution, ETA prediction and refund-risk scoring
- Fairness Aggregator that combines five evidence checks into explainable outcomes, with escalation to human review
- Real-time rider GPS tracking and nearest-rider assignment across six role-based dashboards

### 🚚 [FreshRoute](https://github.com/ThisukaMW/freshroute-backend) — Delivery Route Optimization Platform
[Frontend](https://github.com/ThisukaMW/freshroute-frontend) · [Live](https://freshroute-frontend.vercel.app)

`React Native` `Node.js` `TypeScript` `FastAPI` `Google OR-Tools` `PostgreSQL` `Socket.IO` `Stripe`
- VRPPD solver with pickup-before-delivery and capacity constraints, plus a fallback heuristic
- Driver app with live GPS over JWT-authenticated Socket.IO connections
- Led repo, branching strategy and deployment for a five-person team

### 📄 [RAG Document Q&A](https://github.com/ThisukaMW/rag-document-qa) — Retrieval-Augmented Document Assistant
`Python` `LangChain` `FAISS` `BM25` `Sentence-Transformers` `Groq` `MCP` `Streamlit`
- Hybrid dense + sparse retrieval using Reciprocal Rank Fusion, with page-level citations
- LLM-judged evaluation scoring **18/20 correctness** and **20/20 faithfulness**
- Knowledge base exposed to external AI clients through an MCP server

### 🔐 [GenZipher](https://github.com/ThisukaMW/Genzipher) — Healthcare Security & Trust Platform
**Finalist — GenZipher 1.0** (UCSC × CSSL) · [Live](https://genzipher.vercel.app)

`Node.js` `Express` `MongoDB` `React` `Python`
- Ed25519-signed prescriptions behind a dual-signature dispense gate
- AES-256-GCM encrypted vitals, a hash-chained audit log, TOTP MFA and WebAuthn biometrics

### 🆘 [ResQ](https://github.com/ThisukaMW/Disaster_Management) — Offline-First Disaster Response Platform
`React` `Vite` `Firebase` `Dexie.js` `Leaflet.js`
- Offline-first responder PWA that keeps reports through airplane mode and restarts with zero data loss
- Real-time HQ dashboard with a live incident map
